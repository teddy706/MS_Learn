# KT AX 일방식 혁신 교육 — 실습 자료 정비 작업 내역 (배경 자료)

**작업일**: 2026-08-26
**대상 교육**: AX 일방식 혁신 교육 (M365 Copilot 활용, 네트워크 엔지니어 대상)
**대상 자료**: 발표자료(PPTX) 1건, 프롬프트 관리 시트(XLSX) 2종, 실습용 샘플 데이터 파일 20종

---

## 1. 작업 배경

KT AX 일방식 혁신 교육은 IP망·교환망·전송망 네트워크 엔지니어를 대상으로 M365 Copilot(Word·Excel·PowerPoint·Outlook·Teams) 실무 활용법을 가르치는 사내 교육이다. 교육은 발표자료(`AX일방식혁신_보조교재.pptx`)와, 그 안의 각 실습 유닛(Unit)에 대응하는 "실습 프롬프트 + 샘플 결과 + 개선 프롬프트"를 정리한 관리 시트, 그리고 실습 시 트레이니가 실제로 열어보는 샘플 데이터 파일(CSV/XLSX/DOCX/PPTX/TXT)로 구성된다.

기존 자료를 점검한 결과 다음 세 가지 층위에서 정비가 필요한 상태였다.

1. **프롬프트 관리 시트 자체의 데이터 손상** — 편집 과정에서 쉼표가 열 구분자로 잘못 해석되어 여러 행의 내용이 옆 칸으로 밀려 있었음
2. **프롬프트가 요구하는 샘플 데이터의 부재/불일치** — 예를 들어 "Latency_ms 열의 음수 값을 보정"하라는 실습 프롬프트가 있는데, 실제 샘플 파일에는 해당 컬럼 자체가 없는 등
3. **콘텐츠 커버리지 불균형** — 45개 유닛 대부분이 IP망(백본/5G RAN) 시나리오에 편중되어 있고, 교육 대상인 교환망·전송망 엔지니어를 위한 실습이 전무

아래는 이를 해결하기 위해 진행한 작업을 순서대로 정리한 것이다.

## 2. 작업 내역

### 2.1 프롬프트 관리 시트 데이터 정합성 복구
**대상**: `M365 Copilot 프롬프트 모음 및 샘플 결과 _ 개선안.xlsx`

- 쉼표 파싱 오류로 셀이 밀려 내용이 깨진 9개 행(U09, U18, U19, U25, U26, U30, U33, U34 등)을 원래 열(원본 프롬프트 / 샘플 결과 / 개선안)로 복원
- `#ERROR!` 텍스트만 남아 있던 U14 셀의 원본 프롬프트를 문맥에 맞게 재구성
- U24(L3 스위치 점검 절차 표 변환) 프롬프트에 정작 변환 대상 원문이 빠져 있어, 실습이 가능하도록 프로즈 텍스트를 직접 보완

### 2.2 실습 항목별 필요 샘플 데이터 검토 및 생성
프롬프트 각각이 요구하는 데이터/컬럼과 실제 보유 파일을 대조한 결과, 아래 항목들은 대응하는 샘플 데이터가 없거나 불충분했다. 신규로 제작·보완했다.

| 실습 내용 | 문제 | 조치 |
|---|---|---|
| 시간대별 트래픽 이상치 피벗 | `5G_DL_Traffic` 열 및 시간대별 데이터 없음 | 강남권 24시간 트래픽 데이터 신규 제작(19시 스파이크 설계, +3σ 기준 정확히 검출되도록 수치 역산) |
| Latency 결측치·음수값 정제 | `Latency_ms` 열 자체가 없음 | 빈 셀/`#N/A`/음수값이 섞인 정제 전 데이터 신규 제작 |
| SharePoint 문서 대조(코어망 토폴로지) | 참조 문서 없음 | 4장(백본 이중화) 포함 토폴로지 문서 신규 작성 |
| 음성 메모 전사 → 표 변환 | 전사 텍스트 없음 | 현장 점검 음성메모 전사본 신규 작성(점검자 미기재 등 "확인 필요" 케이스 의도적 포함) |
| 보안 취약점 요약 | 기존 기술보고서에 보안 섹션 없음 | 기술보고서에 5장(N3/N4 인터페이스 보안 취약점) 신규 추가 |
| 릴리즈 노트 핵심 슬라이드 검색(50장 중 3장) | 참조 PPT 없음 | 실제 50슬라이드 분량의 릴리즈 노트 PPT 제작, 샘플 결과에 명시된 14/28/41번 슬라이드에 정확히 해당 내용 배치 |
| 예산 초과 국사 탐색 | 참조 PPT 없음 | 30슬라이드 분량의 예산 집행 현황 PPT 제작, 샘플 결과의 18번(종로 112%)·22번(영등포 108%) 슬라이드 정확히 일치하도록 설계 |
| syslog 기반 BGP Flapping 분석 | 참조 로그 없음 | Severity 1~2 등급 포함 syslog 신규 작성 |

### 2.3 KT 3대 망 도메인 실습 공백 진단 및 추가
발표자료의 45개 유닛을 도메인별로 분류한 결과, IP망(라우팅/백본/5G코어) 비중이 압도적으로 높고 **교환망 실습은 전무, 전송망 실습은 사실상 전무**한 상태임을 확인했다. 특히 전송망→IP망→교환망으로 장애가 전이되는 "복합 장애" 시나리오가 전혀 없다는 점이 가장 큰 공백이었다.

이를 보완하기 위해 Excel 3건, PowerPoint 3건, 총 6개 실습을 신규 설계했다.

| 신규 실습 | 도메인 | 내용 |
|---|---|---|
| DWDM 광파워 이상 채널 탐지 | 전송망 | Rx Level -28dBm 이하 채널 탐지 |
| 국번별 ASR 이상 구간 탐지 | 교환망 | CDR 통계 3σ 이상치 탐지 |
| 라우팅 테이블 증설 시점 예측 | IP망 | Route Count·메모리 사용률 추세 예측 |
| 전송망 100G→400G 증설 계획 슬라이드 | 전송망 | 광파워 데이터 기반 증설 의사결정 자료 |
| TDM→All-IP 전환 로드맵 | 교환망 | 노후 교환기 전환 전략 슬라이드 |
| 3개 망 연쇄 장애 1장 요약 | 복합 | 전송→IP→교환 연쇄 장애 경영진 보고 슬라이드 |

각 실습에 필요한 샘플 데이터(DWDM 광파워 로그, CDR/ASR 통계, 라우팅테이블 추이, 통합 장애 타임라인)를 함께 제작했으며, 수치는 실습에서 요구하는 결과(예: 3σ 이상치가 정확히 특정 행에서만 검출)가 그대로 재현되도록 역산해 설계했다.

### 2.4 실제 발표자료(PPTX)와 프롬프트 시트 대조 검증
**대상**: `AX일방식혁신_보조교재.pptx` (원본 54슬라이드, 45유닛, 표지에 "CHAPTERS 04 / UNITS 45 / SLIDES 51" 명시)

프롬프트 관리 시트가 실제 발표자료를 얼마나 정확히 반영하는지 문장 단위로 전수 대조했다. 발표자료의 "예시 프롬프트" 텍스트를 원천(ground truth)으로 삼아 13곳의 불일치를 발견, 수정했다.

- **오타 1건(중요)**: U31 "이 문단을 명확한 비즈니스 **문제**로 다시 써줘" → 원본은 "**문체**"(tone). 실습 의도 자체가 왜곡되어 있던 오류
- **파일명 불일치 4건**: 이전 작업에서 파일명을 임의로 "정정"했던 것이 오히려 발표자료 원문(짧은 이름: `기술보고서.docx`, `CAPEX_예산안_2026.csv` 등)과 어긋나 있어 원복
- **문장부호/구분자 불일치 8건**: 쉼표 누락, 하이픈(-)과 가운뎃점(·) 혼용 등 경미한 표기 차이

### 2.5 신규 실습 6건을 실제 발표자료에 슬라이드로 반영
2.3에서 설계한 6개 실습을 프롬프트 시트뿐 아니라 실제 PPTX 발표자료에도 슬라이드로 추가했다.

- 기존 유닛의 슬라이드 템플릿(제목/부제 + 좌우 3항목 패널 + "예시 프롬프트" 콜아웃)을 그대로 복제하여 폰트·색상·아이콘 등 시각적 일관성을 유지
- 기존 UNIT 01~45의 번호·배치는 변경하지 않고, UNIT 45와 클로징 슬라이드 사이에 6개 슬라이드(UNIT 46~51) 삽입
- 표지("UNITS 45→51", "SLIDES 51→57"), 커리큘럼 로드맵, 챕터 간지, 클로징 슬라이드, 전체 슬라이드 하단 페이지 번호("NN/54"→"NN/60")까지 연동 갱신
- 작업 중 슬라이드 복제 시 아이콘 이미지의 관계(relationship) 링크가 누락되어 깨지는 버그를 발견, 원본 백업에서 복구 후 재작업하여 해결

결과: **60슬라이드, 51유닛** 체제로 확장.

### 2.6 실습 프롬프트 재정리 버전 반영 및 샘플 데이터 유닛 매핑
이후 발표자료의 실제 슬라이드 배치 순서를 반영해 유닛 번호를 재구성한 신규 관리 시트(`실습 프롬프트_0826.xlsx`)가 만들어졌다. 이 파일은 신규 실습 6건이 관련 기존 유닛 바로 옆(Excel 실습군/PowerPoint 실습군 내부)에 자연스럽게 배치되도록 챕터/유닛 번호를 CH04-U03~U50으로 재부여한 버전이다.

이 최신 매핑을 기준으로 **20개 샘플 데이터 파일 전체에 대응 유닛 번호를 표기**했다. 파일 하나가 여러 유닛에서 재사용되는 경우(예: 5G KPI 품질지표 데이터가 7개 유닛에서 쓰임) 해당 유닛 번호를 모두 표기했다.

정리 과정에서 사용처가 확인되지 않는 파일 2건(미사용 장애로그, 중복 사본 문서)을 삭제했다.

### 2.7 파일 형식 및 명명 규칙 정리
- **CSV → XLSX 일괄 변환**: Excel 실습(피벗 테이블, 조건부 서식, 수식 등)은 정식 워크북이 필요하므로, 남아 있던 CSV 샘플 데이터를 모두 XLSX로 변환(숫자형 컬럼은 문자열이 아닌 실제 숫자로 처리)
- **표기 방식 통일**: 유닛 태그를 대괄호 `[Uxx]` 형식으로 통일하고, 파일명 맨 앞으로 이동시켜 폴더에서 유닛 순서대로 정렬·탐색 가능하도록 정리
