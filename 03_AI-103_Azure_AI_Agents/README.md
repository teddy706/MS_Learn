# AI-103: Developing Generative AI & Agents on Azure
> Microsoft 공식 자격 과정 | Azure 기반 생성형 AI 및 에이전트 개발

---

## 1. 과정 개요
AI-103 과정은 Azure AI Foundry, Semantic Kernel, Model Context Protocol(MCP), Document Intelligence, Azure Speech & Vision을 활용하여 멀티모달 생성형 AI 솔루션 및 지능형 에이전트를 개발하고 배포하는 개발자 전문 과정입니다.

---

## 2. 주요 학습 경로 (4대 Learning Path / 30개 모듈)

1. Path 1: Azure 생성 AI 앱 개발 (Foundry SDK, 모델 카탈로그, 도구 연동)
2. Path 2: Azure AI 에이전트 개발 (커스텀 도구, MCP 서버, Semantic Kernel 다중 에이전트)
3. Path 3: Azure 자연어 & 음성 솔루션 (Language MCP, Speech Voice Live 에이전트)
4. Path 4: 멀티모달 & 시각 지능 추출 (Content Understanding, Document Intelligence)
